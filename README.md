# СберБережно 360 — команда «Сила мыслей»

Демо: http://sberberezhno.ru

- `index.html` — питч («Дальше» или кликер — следующий шаг, ⛶ — полный экран, «+» внизу — подробности для вопросов).
- `prototype.html` — полный прототип (открывается из питча кнопкой «Открыть полный прототип»).

Всё работает офлайн: шрифты встроены, внешних зависимостей нет.

## Деплой

Каждый пуш в `main` автоматически публикуется на GitHub Pages через `.github/workflows/pages.yml`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
